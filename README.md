# 📈 E-Commerce Sales Forecasting using Machine Learning

An end-to-end Data Science and Machine Learning project that analyzes historical e-commerce sales data, identifies demand patterns, and forecasts future product sales using a Random Forest Regression model.

## 🚀 Live Demo

[👉 View the Live Sales Forecasting Dashboard](https://sales-forecasting-ml-zf6ti785yyeyzhjtcpoazm.streamlit.app/)

## 🎯 Problem Statement

E-commerce businesses need accurate demand estimates to make better decisions related to inventory management, sales planning, and product demand.

This project uses historical sales data to:

- Analyze historical sales patterns
- Create meaningful time-based features
- Identify weekly and monthly demand patterns
- Train a Machine Learning model
- Evaluate model performance on unseen test data
- Forecast future product sales
- Present the results through an interactive Streamlit dashboard
