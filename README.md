# 📈 E-Commerce Sales Forecasting using Machine Learning

An end-to-end Data Science project that uses historical e-commerce sales data and Machine Learning to analyze demand patterns and forecast product sales.

## 🎯 Problem Statement

E-commerce businesses need to understand customer demand to make better inventory and sales decisions.

This project analyzes historical sales data, identifies demand patterns, and uses a Random Forest Regression model to forecast future product sales.

## 🚀 Features

- Historical sales analysis
- Data preprocessing
- Feature engineering
- Lag-based demand features
- Rolling sales features
- Random Forest Regression
- Hyperparameter tuning
- Time-series validation
- Sales forecasting
- Weekly seasonality analysis
- Monthly seasonality analysis
- Feature importance analysis
- Interactive Streamlit dashboard
